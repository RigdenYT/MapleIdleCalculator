MAPLESTORY IDLE OPTIMIZER 2.6.8 — PACKAGED STARTUP FIX

PROBLEM
The 2.6.7 Linux single-file build could crash while constructing the interface:

    ModuleNotFoundError: No module named 'PIL._tkinter_finder'

Pillow imports that Tk helper dynamically only when its first ImageTk image is
connected to Tk. PyInstaller therefore did not discover it during normal static
analysis, even though Pillow itself was bundled.

FIX
- The PyInstaller spec explicitly includes PIL._tkinter_finder and PIL._imagingtk.
- Decorative gradient controls have a flat Tk fallback so this class of cosmetic
  failure cannot prevent normal startup.
- Windows and Linux build scripts launch both frozen build formats after creation.
- The application supports --packaging-smoke-test, which constructs the complete
  interface and exits without waiting for user input.
- Linux CI installs Xvfb so the Tk startup check works on the headless runner.

This changes packaging and release validation only. Optimizer formulas and saved
account/build formats are unchanged.

REPOSITORY INSTALLATION NOTE
----------------------------
The .github directory is hidden on Linux desktops. Copying only the visible
files leaves the old GitHub Actions workflow in place. Run:

    ./install_into_repository.sh /full/path/to/MapleIdleCalculator

from the extracted release folder to install all files, including .github.
