MAPLESTORY IDLE OPTIMIZER 2.6.10 — PUBLISH SMOKE TEST FIX
==========================================================

The packaging smoke test now runs with a temporary, isolated configuration root.
It cannot restore or modify the publisher's real last_session.json account.

Why the previous test failed
----------------------------
The persistent role chooser and its Main button were working. However, the
packaged executable restored the publisher's existing account before running the
smoke test. When that account already had every companion slot occupied, the
optimizer correctly rejected adding the test companion as another Main. The test
misreported that valid slot-limit rejection as a role-chooser failure.

What is verified now
--------------------
- The frozen app starts with a clean disposable account.
- Real autosave and UI-preference files are not loaded or changed.
- A badge click opens the persistent chooser and it remains visible after release.
- The Main button's actual Tk command applies Main and closes the chooser.
- Pillow's dynamically imported Tk modules remain bundled.

No optimizer formulas, account formats, or normal user behavior changed.
