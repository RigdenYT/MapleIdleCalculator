MAPLESTORY IDLE OPTIMIZER — RELEASE BUILD NOTES
================================================

The same source is used for Windows and Linux, but PyInstaller must run on the
target operating system. GitHub Actions is the recommended release path because
it provides clean Windows and Linux runners from one repository.

GITHUB ACTIONS — RECOMMENDED
----------------------------
Workflow file:

    .github/workflows/build-desktop-releases.yml

Manual run:
- Open the repository's Actions page.
- Select Build Desktop Releases.
- Select Run workflow.
- Download the Windows and Linux artifacts from the completed run.

Tagged release:
- Ensure APP_VERSION and the current README changelog entry identify the release.
- Commit and push the source.
- Push a tag matching APP_VERSION, for example v3.0.0.

The workflow rejects a tag that does not exactly match APP_VERSION. A successful
tagged run publishes a GitHub Release containing both platforms automatically.
See GITHUB_RELEASES.txt for repository setup and future-release steps.

LOCAL LINUX BUILD
-----------------
1. Install Python 3, Tk, Tesseract, and English Tesseract language data.
2. Run ./build_tools/build_linux.sh
3. Test the generated one-folder archive first.
4. Test screenshot import without relying on a different system Tesseract.
5. Distribute the single-file executable from release/ after testing.

LOCAL WINDOWS BUILD
-------------------
1. Install 64-bit Python 3 with Tcl/Tk.
2. Install a 64-bit Tesseract distribution on the build computer. Testers do not
   need it because the staging script embeds its runtime files.
3. Run build_tools\build_windows.bat
4. Test the generated one-folder archive first.
5. Test screenshot import on a Windows account without Tesseract on PATH.
6. Distribute the single-file EXE from release/ after testing.

BUILD OUTPUTS
-------------
The build scripts create raw PyInstaller output under dist/, launch both the
one-folder and single-file programs with --packaging-smoke-test, and only then
create upload-ready files under release/. Each platform's release directory contains:

- the final single-file executable;
- a compressed one-folder diagnostic build;
- a platform-specific SHA256SUMS file.

No standalone per-version README or update-note TXT is added to release assets.

VERSION METADATA
----------------
APP_VERSION in maplestory_idle_companion_optimizer.py is the version source of
truth. The PyInstaller specification reads it directly. Before every build,
release_metadata.py generates Windows version information, verifies the current
README entry, and rejects legacy root-level per-version update-note files.

Useful commands:

    python build_tools/release_metadata.py --print-version
    python build_tools/release_metadata.py --write-windows-version
    python build_tools/release_metadata.py --check
    python build_tools/release_metadata.py --check-tag v3.0.0

TESSERACT OVERRIDES
-------------------
- Set TESSERACT_HOME on Windows to the folder containing tesseract.exe.
- Set MAPLE_IDLE_TESSERACT to an exact executable path on either platform.
- Set TESSDATA_PREFIX when English trained data is in a nonstandard folder.

OCR runtimes under vendor/ocr/<platform>-<arch> are generated build artifacts.
They are not intended to be committed to the repository.

RELEASE SMOKE TEST
------------------
- Launch without a terminal or Python installed.
- Verify the Fire/Poison Legendary application icon.
- Create a new account and build, save, close, and reopen it.
- Enter companion ownership, levels, Main/Sub roles, and switch builds.
- Import all required Stat Info screenshots and review imported values.
- Optimize a team and run robustness ranges.
- Test Hero Power and Equipment Potential planning, OCR, and reroll workflows.
- Open Help and generate a diagnostic bug-report ZIP.
- Confirm expected use creates no crash log.
- Confirm a forced error is written under the per-user crash_logs folder.
- Verify published files against SHA256SUMS if transfer corruption is suspected.

The first external Windows release may trigger SmartScreen because it is unsigned.
